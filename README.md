# 📧 Agent Gestionnaire d'Emails avec LangGraph

Agent IA capable de comprendre des requêtes en langage naturel et d'envoyer des emails via Gmail.

## 🚀 Fonctionnalités

- ✅ Compréhension du langage naturel
- ✅ Recherche automatique de contacts
- ✅ Rédaction d'emails par IA
- ✅ Demande de confirmation avant envoi
- ✅ Envoi via SMTP
- ✅ Gestion des erreurs et reprises
- ✅ Interface CLI interactive

## ⚙️ Configuration SMTP

Crée un fichier `.env` à la racine du projet avec les variables suivantes :

```env
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=adaouisalah552@@gmail.com
SMTP_PASSWORD=ton_mot_de_passe
SMTP_USE_TLS=true
SMTP_USE_SSL=false
EMAIL_FROM=adaouisalah552@gmail.com
```
